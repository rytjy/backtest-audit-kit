# 一个独立开发者的产出据点

这里不放自我介绍，也不放"我能做什么"的清单。
这里只放**能跑、能查、能被否证**的东西 —— 你不需要先相信我说的话。

---

## 1. `table-tool` · 表格批量整理（能跑）

**是什么**：把多张来源不同的乱表，合并 / 清洗 / 去重 / 汇总 / 导出。

**怎么验**：双击 `table-tool/dist/表格整理工具.html` —— **单文件、零外部依赖、不联网**（已实测：`fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon` 计数均为 0，三个 `<script>` 全部内联）。把 `table-tool/sample/` 里的样例拖进去即可。

**它真正会做、而一般工具常漏的一件事**：报"**字段错位**"——
例如 `3,000` 忘了加引号，导致那一行只有 3 列、表头要 4 列。**Excel 不会提醒你**，你看到的是一张"看起来对"的表，汇总结果静默错掉。

**自检**：`node table-tool/test.js`（14 项）

**边界**：不做需要人工判断的清洗（同名不同人、格式不统一）；不做多表关联；大文件受浏览器内存限制。

## 2. 一份被自己推翻的回测（能查）

`reports/alt-short-backtest-2026-10-03.md`

**是什么**：检验"做空山寨币跌幅榜"是否有 edge。240 天、24 个永续、逐日调仓，**扣真实资金费历史 + 滑点**（换手感知）。

**结论**：**没有 edge** —— 并且亏损主要来自市场 beta，不是"选错了币"。

**为什么它值得看**：报告里有一节叫 **「对抗复核推翻的」**。
我的初版**成本口径是错的** —— 对每个策略都按"逐日全额换手"收费，但各策略的实际换手率差 6 倍（一个 0%、一个 64%），于是对照组的数字全歪了。那一节写的就是**我把它抓出来、重算、修正**的过程。

**边界**（不写清就等于吹）：样本是单边牛市；universe 用"当前流动性"筛选，有幸存者偏差；**没有熊市样本**；未计交易所手续费。

## 3. 一次"两条腿都断了"的修复（能查）

`notes/contest-watch-sherlock-fix.md`

**是什么**：一个监控脚本的第 4 个数据源长期显示"未知"。排查后发现**两个 bug 叠在一起**：
① 未认证 API 配额被打满（403）② 旧数据源已 404 ——
而且**即使这两条都正常，那个字段也从来没有被赋过真值**，所以它永远显示"未知"。

**怎么验**：修复后试跑输出 `sherlock=none`，页面文字 **"All 0 Active"** 独立佐证。

## 这份据点想说什么

三件东西分别证明三件事：**能写能跑的代码** · **会做数据、并且会否证自己** · **会排查别人看两眼就放弃的 bug**。
