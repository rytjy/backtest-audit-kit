# table-tool —— 表格批量整理（合并 / 清洗 / 去重 / 汇总）

> **一句话**：把散落、格式不一致的一堆 Excel / CSV，合并成一张干净的表，并按你要的维度汇总。
> **隐私**：网页版**全部在你自己的浏览器里跑，不联网、不上传任何数据**。

---

## 它能做什么

| 能力 | 说明 |
|---|---|
| **多表合并** | 列名自动对齐（容忍前后空格、全角空格、BOM）；缺列补空；不同列顺序也没问题 |
| **清洗** | 去首尾空白、压缩内部空白、全角空格→半角、空值归一 |
| **数字识别** | `1,200.50` / `¥860` / `12%` → 真正的数字（否则汇总会算错） |
| **去空行** | 整行都空的自动去掉 |
| **去重** | 按整行，或**按指定列**（例如"同一客户只留一条"） |
| **分组汇总** | 按某列分组，做 求和 / 计数 / 平均 / 最大 / 最小 |
| **导出** | CSV（带 BOM，Excel 打开不乱码）、Excel(.xlsx) |

---

## 怎么用

### 方式一：网页版（推荐，零安装）

1. 打开 `index.html`（双击即可，无需服务器）
2. 把 CSV / Excel 拖进虚线框（可多选）
3. 勾选项 → 点「**合并并预览**」→ 看结果 → 导出

> 注意：Excel(.xlsx) 解析依赖联网加载 SheetJS。**离线时请先另存为 CSV** —— CSV 路径完全离线可用。

### 方式二：命令行（批量/自动化）

```bash
node demo.js sample/客户A_订单.csv sample/客户B_订单.csv
```

## 已知边界（不粉饰）

- **只读第一个工作表**（多 sheet 需要时再加）
- 去重是**精确匹配**，不做模糊相似（"张三"与"张三 "会先被清洗成同一个，但"张三"与"张 三"不会）
- 数字识别只在"整格看起来就是数字"时生效，**不做列级猜测**（避免误改文本）
- 大文件（>10 万行）网页版会慢，建议走命令行
